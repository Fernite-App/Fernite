# Fernite Launcher

A desktop application for managing Minecraft mods, modpacks, and instances.

## Development

This is a Tauri-based desktop application with a Vue frontend.

### Prerequisites

- Rust 1.90+
- Node.js 20+
- pnpm 9+

### Building

```bash
# Install dependencies
pnpm install

# Build the app
pnpm app:build
```
